## 1. Passiv with Different Auxiliaries | مجهول با فعل‌های کمکی مختلف

**English:** The passive voice uses **werden** as its auxiliary verb. The tense is determined by the form of *werden*.

**Persian:** مجهول از فعل کمکی **werden** استفاده می‌کند. زمان فعل توسط شکل *werden* تعیین می‌شود.

### Tense Table | جدول زمان‌ها

| Tense | Structure | Example | Translation |
|---|---|---|---|
| **Präsens** | werden + Partizip II | Das Haus **wird gebaut**. | The house is being built. |
| **Präteritum** | wurden + Partizip II | Das Haus **wurde gebaut**. | The house was built. |
| **Perfekt** | ist worden + Partizip II | Das Haus **ist gebaut worden**. | The house has been built. |
| **Plusquamperfekt** | war worden + Partizip II | Das Haus **war gebaut worden**. | The house had been built. |
| **Futur I** | werden + Partizip II werden | Das Haus **wird gebaut werden**. | The house will be built. |
| **Futur II** | werden + Partizip II worden sein | Das Haus **wird gebaut worden sein**. | The house will have been built. |

### Examples | مثال‌ها

```
Präsens:       Das Buch wird gelesen.          (The book is read.)
Präteritum:    Das Buch wurde gelesen.         (The book was read.)
Perfekt:       Das Buch ist gelesen worden.    (The book has been read.)
Plusquamperfekt: Das Buch war gelesen worden.  (The book had been read.)
Futur I:       Das Buch wird gelesen werden.   (The book will be read.)
Futur II:      Das Buch wird gelesen worden sein. (The book will have been read.)
```

## 2. Passiv with Modal Verbs | مجهول با فعل‌های مدال

**English:** Modal verbs combine with passive to express necessity, ability, permission, etc.

**Persian:** فعل‌های مدال با مجهول ترکیب می‌شوند تا ضرورت، توانایی، اجازه و غیره را بیان کنند.

### Structure | ساختار

| Modal | Tense | Structure | Example |
|---|---|---|---|
| **müssen** | Präsens | modal + Partizip II + werden | Das muss **gemacht werden**. |
| **müssen** | Präteritum | modal + Partizip II + werden | Das musste **gemacht werden**. |
| **können** | Präsens | modal + Partizip II + werden | Das kann **gemacht werden**. |
| **können** | Präteritum | modal + Partizip II + werden | Das konnte **gemacht werden**. |
| **dürfen** | Präsens | modal + Partizip II + werden | Das darf **nicht gemacht werden**. |
| **dürfen** | Präteritum | modal + Partizip II + werden | Das durfte **nicht gemacht werden**. |
| **sollen** | Präsens | modal + Partizip II + werden | Das soll **gemacht werden**. |
| **wollen** | Präsens | modal + Partizip II + werden | Das wird **gemacht werden wollen**. |
| **werden** | Präsens | werden + Partizip II + werden | Das wird **gemacht werden**. |

### Examples | مثال‌ها

```
Das Auto muss repariert werden.        (The car must be repaired.)
Die Tür konnte nicht geöffnet werden.   (The door could not be opened.)
Hier darf nicht geraucht werden.        (Smoking is not permitted here.)
Das Projekt soll bis Montag fertig sein. (The project is to be finished by Monday.)
```

## 3. Passiv Nominativ (Wer wird gefragt?) | مجهول نواسبت (چه کسی پرسیده می‌شود؟)

**English:** In passive constructions, the original object becomes the subject (nominative), and the original subject becomes the agent (von + dative).

**Persian:** در ساختارهای مجهول، مفعول اصلی فاعل (حالت نواسبت) می‌شود، و فاعل اصلی عامل (von + حالت جرّ) می‌شود.

### Transformation Table | جدول تبدیل

| Aktiv | Passiv (Nominativ) | Agent (von + Dativ) |
|---|---|---|
| Der Arzt **untersucht** den Patienten. | Der Patient **wird untersucht**. | **vom Arzt** |
| Die Lehrerin **korrigiert** die Klausur. | Die Klausur **wird korrigiert**. | **von der Lehrerin** |
| Man **öffnet** die Tür. | Die Tür **wird geöffnet**. | **(von niemandem)** |
| Die Firma **stellt** neue Mitarbeiter ein. | Neue Mitarbeiter **werden eingestellt**. | **von der Firma** |

### Questions | سؤالات

```
Wer wird gefragt?      → Der Student wird gefragt.
Was wird gefragt?      → Die Frage wird gestellt.
Wann wird gebaut?      → Das Haus wird nächstes Jahr gebaut.
Wo wird gearbeitet?    → Hier wird gearbeitet.
Von wem wird das gemacht? → Das wird vom Chef gemacht.
```

## 4. Passiv with Impersonal Subjects | مجهول با فاعل‌های غیرشخصی

**English:** German uses impersonal passives with "es" or without a subject to describe general situations or events without a specific agent.

**Persian:** آلمانی از مجهول غیرشخصی با "es" یا بدون فاعل استفاده می‌کند تا موقعیت‌ها یا رویدادهای عمومی را بدون عامل خاص توصیف کند.

### Es + werden + Partizip II

| Example | Translation |
|---|---|
| **Es wird** hier viel **geredet**. | There is a lot of talking here. |
| **Es wird** getanzt und gesungen. | People are dancing and singing. |
| **Es wird** um Hilfe **gerufen**. | Someone is calling for help. |
| **Es wurde** viel **gelacht**. | There was a lot of laughing. |

### Without "es" (Formal)

| Example | Translation |
|---|---|
| **Wird** hier gearbeitet? | Is work being done here? |
| **Wurde** gestern gefeiert? | Was there celebrating yesterday? |
| Hier **wird** nicht **geredet**! | No talking here! |
| Auf dieses Problem **wird** hingewiesen. | Attention is drawn to this problem. |

## 5. Passiv with "sein" (Zustandspassiv) | مجهول با "sein" (مجهول حالتی)

**English:** "Zustandspassiv" describes a state resulting from an action, using **sein** instead of *werden*.

**Persian:** "مجهول حالتی" وضعیت حاصل از یک عمل را توصیف می‌کند و به جای *werden* از **sein** استفاده می‌شود.

### Werden-Passiv vs. Sein-Passiv

| Werden-Passiv (Process) | Sein-Passiv (State) |
|---|---|
| Die Tür **wird** geöffnet. | Die Tür **ist** geöffnet. |
| (The door is being opened.) | (The door is open.) |
| Das Fenster **wurde** zerbrochen. | Das Fenster **ist** zerbrochen. |
| (The window was broken [action].) | (The window is broken [state].) |
| Die Suppe **wird** gekocht. | Die Suppe **ist** gekocht. |
| (The soup is being cooked.) | (The soup is cooked.) |

---

## 6. Passiv with Different Cases | مجهول با حالت‌های مختلف

### Dative Passiv (Rezipientenpassiv) | مجهول حالت مخاطب

```
Mir wird geholfen.           (I am being helped.)
Ihm wurde eine Belohnung gegeben.  (He was given a reward.)
Den Kindern wird gespielt.   (The children are being played with.)
```

### Akkusativ Passiv | مجهول حالت مفعولی

```
Das Buch wird gelesen.       (The book is being read.)
Die Fehler wurden korrigiert. (The errors were corrected.)
```

| Das Essen **muss** bis 12 Uhr **fertig sein**. | The food must be ready by 12. | غذا باید تا ساعت 12 آماده باشد. |
