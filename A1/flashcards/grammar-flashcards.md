## Case System

### Akkusativ vs. Dativ

#### Front
**Akkusativ** = ______ object (who/what?)
**Dativ** = ______ object (to whom/for whom?)

**Example:**
- Ich sehe **den Mann**. → ______ case
- Ich gebe **dem Mann** das Buch. → ______ case

#### Back
- **Akkusativ** = direct object (مفعول مستقیم) - who/what receives the action
- **Dativ** = indirect object (مفعول غیرمستقیم) - to whom/for whom

- Ich sehe **den Mann**. → **Akkusativ** (I see the man.)
- Ich gebe **dem Mann** das Buch. → **Dativ** (I give the man the book.)

### Irregular Verbs (sein, haben, werden)

#### Front
**sein** conjugation:
ich ______, du ______, er/sie/es ______, wir ______, ihr ______, sie/Sie ______

**haben** conjugation:
ich ______, du ______, er/sie/es ______, wir ______, ihr ______, sie/Sie ______

#### Back
**sein** (to be / بودن):
ich **bin**, du **bist**, er/sie/es **ist**, wir **sind**, ihr **seid**, sie/Sie **sind**

**haben** (to have / داشتن):
ich **habe**, du **hast**, er/sie/es **hat**, wir **haben**, ihr **habt**, sie/Sie **haben**

## سیستم حالت

### آکوزاتیو در مقابل داتیو

#### جلو
**آکوزاتیو** = مفعول ______ (چه کسی/چه چیزی؟)
**داتیو** = مفعول ______ (به چه کسی/برای چه کسی؟)

#### پشت
- **آکوزاتیو** = مفعول مستقیم - چه کسی/چه چیزی عمل را دریافت می‌کند
- **داتیو** = مفعول غیرمستقیم - به چه کسی/برای چه کسی
