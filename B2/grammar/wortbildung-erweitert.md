## 1. Advanced Prefixes (Verben) | پیشوندهای پیشرفته (فعل‌ها)

**English:** German verb prefixes change meaning significantly. Some are separable, some inseparable.

**Persian:** پیشوندهای فعل آلمانی معنی را به‌طور قابل‌توجهی تغییر می‌دهند. برخی جداشدنی و برخی غیرقابل جداسازی هستند.

### Inseparable Prefixes | پیشوندهای غیرقابل جداسازی

| Prefix | Meaning | Examples |
|---|---|---|
| **miss-** | wrong, bad | miss**verstehen** (misunderstand), miss**achten** (disregard) |
| **ent-** | un-, de-, dis- | ent**decken** (discover), ent**lassen** (dismiss), ent**scheiden** (decide) |
| **zer-** | apart, to pieces | zer**brechen** (break), zer**stören** (destroy), zer**legen** (disassemble) |
| **er-** | achieve, cause | er**reichen** (reach/achieve), er**klären** (explain), er**fahren** (experience) |
| **ver-** | change, away | ver**ändern** (change), ver**kaufen** (sell), ver**gessen** (forget) |
| **be-** | make, about | be**achten** (notice), be**schreiben** (describe), be**kommen** (receive) |
| **ge-** | past participle marker | ge**schrieben** (written), ge**macht** (made) |
| **emp-** (empf-) | receive | emp**fangen** (receive), emp**fehlen** (recommend) |
| **ent-** | remove, away | ent**fernen** (remove), ent**wickeln** (develop) |
| **wider-** | against | wider**stehen** (resist), wider**sprechen** (contradict) |

### Separable Prefixes | پیشوندهای جداشدنی

| Prefix | Meaning | Examples |
|---|---|---|
| **ab-** | off, away | ab**fahren** (depart), ab**geben** (give away) |
| **an-** | on, to | an**kommen** (arrive), an**fangen** (begin) |
| **auf-** | up, open | auf**stehen** (get up), auf**machen** (open) |
| **aus-** | out, from | aus**gehen** (go out), aus**sprechen** (pronounce) |
| **ein-** | in, into | ein**steigen** (get in), ein**laden** (invite) |
| **mit-** | with | mit**nehmen** (take along), mit**machen** (participate) |
| **nach-** | after, to | nach**denken** (think about), nach**fragen** (ask) |
| **vor-** | before, forward | vor**stellen** (introduce), vor**lesen** (read aloud) |
| **zu-** | to, closed | zu**machen** (close), zu**stimmen** (agree) |
| **zurück-** | back | zurück**kommen** (come back), zurück**geben** (give back) |

### Verb + Suffix = Noun | فعل + پسوند = اسم

| Verb | Suffix | Noun |
|---|---|---|
| regnen | -er | der **Regner** (rainfall) |
| lesen | -ung | die **Lesung** (reading) |
| hören | -er | der **Hörer** (listener) |

## 2. Advanced Suffixes (Nomen) | پسوندهای پیشرفته (اسم)

**English:** Suffixes determine a noun's gender and meaning category.

**Persian:** پسوندها جنسیت و دسته معنایی اسم را تعیین می‌کنند.

### Noun Suffixes | پسوندهای اسم

| Suffix | Gender | Meaning | Examples |
|---|---|---|---|
| **-keit** | die (f.) | -ness, -ty | die Schön**heit** (beauty) — actually -heit |
| **-heit** | die (f.) | -ness, -ty | die Frei**heit** (freedom), die Gesund**heit** (health) |
| **-schaft** | die (f.) | -ship, -hood | die Freund**schaft** (friendship), die Wissenschaft (science) |
| **-ung** | die (f.) | -ing, -tion | die Zeit**ung** (newspaper), die Bezeichn**ung** (designation) |
| **-nis** | die/der (f./n.) | -ness, -ty | die Kennt**nis** (knowledge), das Ergebn**is** (result) |
| **-ling** | der (m.) | -ling, -ling | der Schütz**ling** (protégé), der Lieb**ling** (favorite) |
| **-tum** | der (n.) | -dom, -ship | das König**tum** (kingdom), das Eigent**um** (property) |
| **-ei** | die (f.) | -ery, -ry | die Bäck**erei** (bakery), die Mal**erei** (painting) |

### Adjective → Noun | صفت → اسم

| Suffix | Gender | Examples |
|---|---|---|
| **-er** | der (m.) | der Reich**er** (the rich one) |
| **-ling** | der (m.) | der Deutsche → der Deutsch**ling** |
| **-nis** | die (f.) | die Kenntnis (the known) |

## 3. Advanced Suffixes (Adjektive) | پسوندهای پیشرفته (صفت)

### Adjective Suffixes | پسوندهای صفت

| Suffix | Meaning | Examples |
|---|---|---|
| **-lich** | -ly, -ful | freund**lich** (friendly), köst**lich** (delicious) |
| **-bar** | -able, -ible | mög**lich** (possible), trink**bar** (drinkable) |
| **-sam** | -some, -ful | lang**sam** (slow), aufrich**tig** — actually -ig |
| **-ig** | -y, -ish | farb**ig** (colorful), reich**ig** (abundant) |
| **-isch** | -ic, -ical | Deutsch**isch** — actually: wissenschaft**lich** |
| **-los** | -less | hoffnungs**los** (hopeless), end**los** (endless) |
| **-voll** | -ful | sinn**voll** (meaningful), kraft**voll** (powerful) |
| **-arm** | -poor | ressourcen**arm** (resource-poor) |
| **-reich** | -rich | kultur**reich** (culturally rich) |
| **-mäßig** | -like, -ly | gesetz**mäßig** (legal), regel**mäßig** (regular) |

## 4. Compound Nouns (Complex) | اسم‌های مرکب (پیچیده)

**English:** German compound nouns can have 3+ parts. The gender is always determined by the last word.

**Persian:** اسم‌های مرکب آلمانی می‌توانند ۳+ بخش داشته باشند. جنسیت همیشه توسط آخرین کلمه تعیین می‌شود.

### Structure | ساختار

```
Linkselement + Grundwort = Kompositum
(left element) + (head word) = (compound noun)
```

### Examples | مثال‌ها

| Compound | Breakdown | Gender |
|---|---|---|
| **Handschuh** | Hand + Schuh | der (m.) — because of Schuh |
| **Kühlschrank** | kühl + Schrank | der (m.) — because of Schrank |
| **Staubsauger** | Staub + Sauger | der (m.) — because of Sauger |
| **Weihnachtsmann** | Weihnachten + Mann | der (m.) — because of Mann |
| **Geburtstagskuchen** | Geburtstag + Kuchen | der (m.) — because of Kuchen |
| **Badezimmer** | Bad + Zimmer | das (n.) — because of Zimmer |
| **Waschmaschine** | Wasch(en) + Maschine | die (f.) — because of Maschine |

### Complex Compounds | اسم‌های مرکب پیچیده

| Compound | Breakdown | Meaning |
|---|---|---|
| **Geschwindigkeitsbeschränkung** | Geschwindigkeit + Beschränkung | speed limit |
| **Arbeitsunfähigkeitsversicherung** | Arbeitsunfähigkeit + Versicherung | disability insurance |
| **Donaudampfschifffahrtsgesellschaft** | Donau + Dampf + Schifffahrt + Gesellschaft | Danube steamship company |
| **Rindfleischetikettierungsüberwachungsaufgabenübertragungsgesetz** | (10 parts!) | beef labeling monitoring law |
