## Import Instructions

1. Copy the content below into a text file (e.g., `german_a1_deck.txt`)
2. Open Anki → File → Import
3. Select the file
4. Set separator to **Tab**
5. Set field 1 = Front, field 2 = Back

## GRAMMAR FLASHCARDS (Front → Back)

```

Artikel Tabelle - Unbestimmt	ein/eine/ein (Nom) → einen/eine/ein (Akk) → einem/einer/einem (Dat) → eines/einer/eines (Gen)
Artikel Tabelle - Kein	kein/keine/kein (Nom) → keinen/keine/kein (Akk) → keinem/keiner/keinem (Dat) → keines/keiner/keines (Gen)
Akkusativ Regel	Nur der → den ändert sich | Akk = Direktes Objekt (wen? was?) | Ich sehe den Mann.
Dativ Regel	dem/der/dem/den(+n) | Dat = Indirektes Objekt (wem?) | Ich gebe dem Mann das Buch.
Genitiv Regel	des(+s/es)/der/des(+s/es)/der | Gen = Besitz (wessen?) | Das ist das Auto des Mannes.
Possessivartikel mein	mein/meine/mein (Nom) → meinen/meine/mein (Akk) → meinem/meiner/meinem (Dat) → meines/meiner/meines (Gen)
Possessivartikel dein	dein/deine/dein (Nom) → deinen/deine/dein (Akk) → deinem/deiner/deinem (Dat) → deines/deiner/deines (Gen)
Possessivartikel sein	sein/seine/sein (Nom) → seinen/seine/sein (Akk) → seinem/seiner/seinem (Dat) → seines/seiner/seines (Gen)
Possessivartikel ihr	ihr/ihre/ihr (Nom) → ihren/ihre/ihr (Akk) → ihrem/ihrer/ihrem (Dat) → ihres/ihrer/ihres (Gen)
Personalpronomen	ich → mich → mir | du → dich → dir | er → ihn → ihm | sie → sie → ihr | es → es → ihm | wir → uns → uns | ihr → euch → euch | sie → sie → ihnen | Sie → Sie → Ihnen
Reflexivpronomen	Akk: mich/dich/sich/sich/sich/uns/euch/sich/sich | Dat: mir/dir/sich/sich/sich/uns/euch/sich/sich
Konjugation Präsens	Pronomen + Endung: ich(-e), du(-st), er/sie/es(-t), wir(-en), ihr(-t), sie/Sie(-en)

Partizip II Regular	ge- + Stamm + -t | gemacht, gearbeitet, gekauft, gespielt
Partizip II Irregular	ge- + veränderter Stamm + -en | gegangen, gekommen, gefahren, gegessen
