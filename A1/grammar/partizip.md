## What is Partizip II?

The **Partizip II** (past participle) is used to form the **Perfekt** tense and as an **adjective**. It's essential for spoken German.

## Formation Rules

### 1. Regular Verbs (Regelmäßige Verbs)

**ge- + stem + -t**

| Infinitive | Stem | Partizip II | English | Persian |
|------------|------|-------------|---------|---------|
| machen | mach- | **ge-mach-t** | done | انجام شده |
| spielen | spiel- | **ge-spiel-t** | played | بازی شده |
| lernen | lern- | **ge-lern-t** | learned | یاد گرفته شده |
| kaufen | kauf- | **ge-kauf-t** | bought | خریداری شده |
| arbeiten | arbeit- | **ge-arbeit-t** | worked | کار شده |

**Special case: Verbs ending in -ieren**
- No **ge-** prefix
- Only **-t** ending

| Infinitive | Partizip II | English | Persian |
|------------|-------------|---------|---------|
| studieren | **studier-t** | studied | تحصیل کرده |
| telefonieren | **telefonier-t** | telephoned | تلفن زده |
| informieren | **informier-t** | informed | اطلاع رسانی شده |
| fotografieren | **fotografier-t** | photographed | عکس گرفته |

### 2. Irregular Verbs (Unregelmäßige Verbs)

**ge- + changed stem + -en**

| Infinitive | Stem Change | Partizip II | English | Persian |
|------------|-------------|-------------|---------|---------|
| gehen | -gang- | **ge-gang-en** | gone | رفته |
| kommen | -komm- | **ge-komm-en** | come | آمده |
| fahren | -fahr- | **ge-fahr-en** | driven | رانده شده |
| essen | -gess- | **ge-gess-en** | eaten | خورده شده |
| trinken | -trunk- | **ge-trunk-en** | drunk | نوشيده شده |
| schlafen | -schlaf- | **ge-schlaf-en** | slept | خوابیده |
| sehen | -seh- | **ge-seh-en** | seen | دیده شده |
| lesen | -les- | **ge-les-en** | read | خوانده شده |
| schreiben | -schrieb- | **ge-schrieb-en** | written | نوشته شده |
| finden | -fund- | **ge-fund-en** | found | پیدا شده |

### 3. Separable Verbs (Trennbare Verbs)

**prefix + ge + stem + -t/-en**

| Infinitive | Partizip II | English | Persian |
|------------|-------------|---------|---------|
| anfangen | **an-ge-fang-en** | started | شروع شده |
| aufstehen | **auf-ge-stand-en** | gotten up | بلند شده |
| einkaufen | **ein-ge-kauf-t** | shopped | خرید شده |
| anrufen | **an-ge-ruf-en** | called | زنگ زده شده |
| fernsehen | **fern-ge-seh-en** | watched TV | تلویزیون تماشا شده |
| mitnehmen | **mit-ge-nomm-en** | taken along | با خود برده شده |

### 4. Inseparable Verbs (Untrennbare Verbs)

**No ge- prefix** (be-, er-, ent-, ver-, zer-, ge-, miss-)

| Infinitive | Partizip II | English | Persian |
|------------|-------------|---------|---------|
| besuchen | **besuch-t** | visited | بازدید شده |
| verstehen | **verstand-en** | understood | فهمیده شده |
| vergessen | **vergess-en** | forgotten | فراموش شده |
| beginnen | **begonn-en** | begun | شروع شده |
| erzählen | **erzählt** | told | تعریف شده |
| empfehlen | **empfohl-en** | recommended | توصیه شده |

## Partizip II as Adjective

| Partizip II | English | Persian | Example |
|-------------|---------|---------|---------|
| geöffnet | opened | باز شده | die geöffnete Tür (the opened door) |
| geschlossen | closed | بسته شده | das geschlossene Fenster (the closed window) |
| gekauft | bought | خریداری شده | das gekaufte Buch (the bought book) |
| gemacht | done | انجام شده | die gemachte Hausaufgabe (the done homework) |

## Summary Table

| Type | Rule | Example |
|------|------|---------|
| Regular | ge- + stem + -t | gemacht |
| -ieren verbs | stem + -t (no ge-) | studiert |
| Irregular | ge- + changed stem + -en | gegangen |
| Separable | prefix + ge + stem + -t/-en | angefangen |
| Inseparable | stem + -t/-en (no ge-) | besucht |

# شکل سوم فعل (پارتیزیپ II)

## شکل سوم فعل چیست؟

**شکل سوم فعل** (پارتیزیپ II) برای ساختن زمان **کامل** و به عنوان **صفت** استفاده می‌شود. برای زبان آلمانی مکالمه ضروری است.

## قوانین ساختار

### ۱. افعال منظم

**ge- + ریشه + -t**

| مصدر | ریشه | شکل سوم | انگلیسی | فارسی |
|------|------|---------|---------|-------|
| machen | mach- | **ge-mach-t** | done | انجام شده |
| spielen | spiel- | **ge-spiel-t** | played | بازی شده |
| lernen | lern- | **ge-lern-t** | learned | یاد گرفته شده |
| kaufen | kauf- | **ge-kauf-t** | bought | خریداری شده |

**نکته: افعالی که به -ieren ختم می‌شوند**
- پیشوند **ge-** ندارند
- فقط پایان **-t** دارند

| مصدر | شکل سوم | انگلیسی | فارسی |
|------|---------|---------|-------|
| studieren | **studier-t** | studied | تحصیل کرده |
| telefonieren | **telefonier-t** | telephoned | تلفن زده |

### ۲. افعال نامنظم

**ge- + ریشه تغییر یافته + -en**

| مصدر | تغییر ریشه | شکل سوم | انگلیسی | فارسی |
|------|------------|---------|---------|-------|
| gehen | -gang- | **ge-gang-en** | gone | رفته |
| kommen | -komm- | **ge-komm-en** | come | آمده |
| fahren | -fahr- | **ge-fahr-en** | driven | رانده شده |
| essen | -gess- | **ge-gess-en** | eaten | خورده شده |
| trinken | -trunk- | **ge-trunk-en** | drunk | نوشيده شده |
| schlafen | -schlaf- | **ge-schlaf-en** | slept | خوابیده |
| sehen | -seh- | **ge-seh-en** | seen | دیده شده |
| lesen | -les- | **ge-les-en** | read | خوانده شده |
| schreiben | -schrieb- | **ge-schrieb-en** | written | نوشته شده |
| finden | -fund- | **ge-fund-en** | found | پیدا شده |

### ۳. افعال جداشدنی

**پیشوند + ge + ریشه + -t/-en**

| مصدر | شکل سوم | انگلیسی | فارسی |
|------|---------|---------|-------|
| anfangen | **an-ge-fang-en** | started | شروع شده |
| aufstehen | **auf-ge-stand-en** | gotten up | بلند شده |
| einkaufen | **ein-ge-kauf-t** | shopped | خرید شده |
| anrufen | **an-ge-ruf-en** | called | زنگ زده شده |

### ۴. افعال جدانشدنی

**بدون پیشوند ge-** (be-, er-, ent-, ver-, zer-, ge-, miss-)

| مصدر | شکل سوم | انگلیسی | فارسی |
|------|---------|---------|-------|
| besuchen | **besuch-t** | visited | بازدید شده |
| verstehen | **verstand-en** | understood | فهمیده شده |

| نوع | قانون | مثال |
