# 🇩🇪 Deutsch Lernen — Personal German Study Notes

A structured, bilingual (Persian/English) reference for learning German, organized by CEFR level.

## 📚 Structure

```
Deutsch/
├── A1/
│   ├── vocabulary/

│   │   └── verbs.md          # Verbs with conjugation and tense forms
│   └── grammar/
│       ├── artikel.md        # Articles (der/die/das)
│       ├── konjugation.md    # Verb conjugation
```

## 🎯 Target Audience

Persian speakers learning German from scratch (A1 and beyond).

## 📖 Format

- Nouns include article color codes: 🔵 Maskulin · 🔴 Feminin · 🟢 Neutral · 🟡 Plural
- Verbs include Präteritum, Perfekt, and irregular/regular classification
- All entries have Persian + English translations
