## 📝 B2 Grammar Rules
### قواعد دستوری B2

### Konjunktiv II (Advanced)
| Rule | Example | Persian |
|------|---------|---------|
| Würde + Infinitiv (substitute for Präteritum) | Ich würde reisen, wenn... | سفر می‌کردم اگر... |
| Hätte + Partizip II (irreal past) | Ich hätte das gemacht | آن را انجام داده بودم |
| Könnte + Infinitiv (possibility) | Das könnte stimmen | ممکن است درست باشد |
| Müsste + Infinitiv (necessity) | Er müsste kommen | باید بیاید |
| conditional sentences | Wenn ich Zeit hätte, würde ich lesen | اگر وقت داشتم، می‌خواندم |

### Passiv (Complex)
| Rule | Example | Persian |
|------|---------|---------|
| Passiv Präsens | Das Buch wird gelesen | کتاب خوانده می‌شود |
| Passiv Perfekt | Das Buch ist gelesen worden | کتاب خوانده شده است |
| Passiv Futur | Das Buch wird gelesen werden | کتاب خوانده خواهد شد |
| Vorgangspassiv (dynamic) | Die Stadt wird gebaut | شهر در حال ساخته شدن است |
| Zustandspassiv (stative) | Die Stadt ist gebaut | شهر ساخته شده است |

### Word Formation
| Rule | Example | Persian |
|------|---------|---------|
| Verben → Nomen (nominalization) | die Entwicklung (from entwickeln) | توسعه (از توسعه دادن) |
| Adjektiv → Nomen | die Größe (from groß) | بزرگی (از بزرگ) |
| Verben → Adjektiv | lesbar (from lesen) | خواندنی (از خواندن) |
| Nomen → Adjektiv | wirtschaftlich (from Wirtschaft) | اقتصادی (از اقتصاد) |
| Verben → Nomen (-ung) | die Bildung (from bilden) | آموزش (از آموزش دادن) |
