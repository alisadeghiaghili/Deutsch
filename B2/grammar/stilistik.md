## 1. Formal vs. Informal Register | سبک رسمی در مقابل غیررسمی

**English:** Register refers to the level of formality in language. Choosing the right register is essential for effective communication.

**Persian:** سبک زبانی به سطح رسمی بودن زبان اشاره دارد. انتخاب سبک مناسب برای ارتباط مؤثر ضروری است.

### Comparison Table | جدول مقایسه

| Feature | Formal (RFormell) | Informal (Umgangssprache) |
|---|---|---|
| **Pronoun** | Sie | du / ihr |
| **Verb position** | Standard (V2) | Flexible, sometimes V-final |
| **Vocabulary** | Hochdeutsch | Dialekt, slang |
| **Questions** | Können Sie mir helfen? | Kannst du mir helfen? |
| **Greetings** | Sehr geehrte Damen und Hallo! / Tschüss! |
| **Closing** | Mit freundlichen Grüßen | Liebe Grüße |
| **Contractions** | ich bin | ich bin's |
| **Nebensatz** | ..., dass ich komme. | ..., dass ich komm. |

### Examples | مثال‌ها

```
Formal:    Ich möchte Ihnen mitteilen, dass das Meeting verschoben wird.
Informal:  Ich wollte dir sagen, das Meeting ist verschoben.

Formal:    Könnten Sie mir bitte das Salt reichen?
Informal:  Kannst du mir mal das Salz reichen?

Formal:    Sehr geehrter Herr Müller, ich schreibe Ihnen wegen...
Informal:  Hallo Herr Müller, ich schreibe wegen...
```

## 2. Academic Writing Style | سبک نوشتاری دانشگاهی

**English:** Academic German uses complex sentence structures, passive voice, nominalizations, and formal vocabulary.

**Persian:** نوشتار دانشگاهی آلمانی از ساختارهای جمله پیچیده، مجهول، اسم‌سازی و واژگان رسمی استفاده می‌کند.

### Key Features | ویژگی‌های کلیدی

| Feature | Example |
|---|---|
| **Passive voice** | Die Ergebnisse **wurden analysiert**. |
| **Nominalization** | Die **Untersuchung** der Daten ergab... |
| **Complex sentence** | Im Rahmen dieser Studie, die sich mit der Frage beschäftigt, ob... |
| **Formal vocabulary** | Es ist **davon auszugehen**, dass... |
| **Hedging** | Die Ergebnisse **deuten darauf hin**, dass... |
| **Citation** | Laut einer Studie von Müller (2020)... |

### Academic Phrases | عبارات دانشگاهی

| German | English | Persian |
|---|---|---|
| Es ist davon auszugehen, dass... | It is to be assumed that... | فرض بر این است که... |
| Die Ergebnisse zeigen, dass... | The results show that... | نتایج نشان می‌دهد که... |
| Im Vergleich zu... | In comparison to... | در مقایسه با... |
| Im Gegensatz zu... | In contrast to... | در مقابل... |
| Zusammenfassend lässt sich sagen... | In summary... | به طور خلاصه... |

## 3. Journalistic Style | سبک روزنامه‌نگاری

**English:** Journalistic German uses short sentences, present tense, vivid language, and often Konjunktiv I for indirect speech.

**Persian:** روزنامه‌نگاری آلمانی از جملات کوتاه، زمان حال، زبان زنده و اغلب کانژونکتیو I برای گزارش غیرمستقیم استفاده می‌کند.

### Key Features | ویژگی‌های کلیدی

| Feature | Example |
|---|---|
| **Short sentences** | Die Regierung handelt. Sofort. |
| **Present tense** | Der Minister **sagt**, er **sei** unschuldig. |
| **Konjunktiv I** | Er sagt, er **habe** nichts gewusst. |
| **Headline style** | Minister tritt zurück |
| **Active voice** | Die Polizei **verhaftet** den Täter. |
| **Numbers/dates** | Am Montag, den 15. März, um 14 Uhr... |

### Journalistic Phrases | عبارات روزنامه‌نگاری

| German | English | Persian |
|---|---|---|
| Laut Augenzeugen... | According to eyewitnesses... | طبق شاهدان عینی... |
| Wie die Zeitung berichtet... | As the newspaper reports... | طبق گزارش روزنامه... |
| Der Minister teilte mit... | The minister announced... | وزیر اعلام کرد... |
| Es heißt, dass... | It is said that... | گفته می‌شود که... |

## 4. Literary Style | سبک ادبی

**English:** Literary German uses rich vocabulary, metaphor, complex structures, and often Konjunktiv II for narrative effect.

**Persian:** ادبیات آلمانی از واژگان غنی، استعاره، ساختارهای پیچیده و اغلب کانژونکتیو II برای اثر روایی استفاده می‌کند.

### Key Features | ویژگی‌های کلیدی

| Feature | Example |
|---|---|
| **Konjunktiv II** | Wenn ich ein Vöglein wär'... |
| **Metaphor** | Das Leben ist ein Traum. |
| **Inversion** | Groß war der Garten. |
| **Partizipialattribute** | Der vom Wind getragene Duft... |
| **Literary vocabulary** | Er wandelte durch die stille Nacht. |

### Literary Phrases | عبارات ادبی

| German | English | Persian |
|---|---|---|
| Es war einmal... | Once upon a time... | روزی روزگاری... |
| Der Sommer neigte sich dem Ende zu. | Summer was drawing to a close. | تابستان به پایان خود نزدیک می‌شد. |
| Stille durchdrang den Raum. | Silence pervaded the room. | سکوت فضا را فرا گرفته بود. |
| Die Welt da draußen... | The world out there... | دنیای بیرون... |

## 5. Register Switching | تغییر سبک زبانی

**English:** Good speakers switch registers depending on the situation.

**Persian:** گویندگان خوب بسته به موقعیت سبک زبانی را تغییر می‌دهند.

### When to Switch | چه زمانی تغییر دهیم

| Situation | Register | Example |
|---|---|---|
| Job interview | Very formal | Ich bewerbe mich um die Stelle als... |
| Business meeting | Formal | Ich möchte Ihnen die Ergebnisse vorstellen. |
| Talking to colleagues | Semi-formal | Ich wollte euch kurz über die Ergebnisse informieren. |
| Talking to friends | Informal | Ich hab' euch was zu erzählen! |
| Writing an email to boss | Very formal | Sehr geehrter Herr Dr. Müller... |
| Texting a friend | Very informal | Hey, alles klar? |
| Academic paper | Academic | Im Rahmen dieser Untersuchung... |
| Newspaper article | Journalistic | Der Minister sagte, er sei... |

### Signal Words for Each Register | کلمات سیگنال هر سبک

| Register | Signal Words |
|---|---|
| **Very formal** | sehr geehrte, hiermit, beabsichtigen, gestatten Sie |
| **Formal** | gerne, möchte, können Sie, bitte |
| **Semi-formal** | ich wollte, kurz, mal, obwohl |
| **Informal** | hey, cool, super, krass, Alter |
| **Academic** | im Rahmen, beziehungsweise, darüber hinaus, jedoch |
| **Journalistic** | laut, wie, berichtet, teilte mit, nach Angaben |

## 6. Summary Table | جدول خلاصه

| Style | Key Feature | Example Sentence |
|---|---|---|
| **Formal** | Sie, complete sentences | Ich möchte Sie bitten, das Dokument zu prüfen. |
| **Informal** | du, contractions | Kannst du mal das Dokument anschauen? |
| **Academic** | Passive, nominalization | Die Daten wurden im Rahmen einer Studie analysiert. |
| **Journalistic** | Konj. I, short sentences | Der Minister sagte, er sei unschuldig. |
