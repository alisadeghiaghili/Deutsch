## Numbers 21-99 (Compound)

Format: **unit + und + ten**
- 21 = **einundzwanzig** (یک و بیست)
- 32 = **zweiunddreißig** (دو و سی)
- 45 = **fünfundvierzig** (پنج و چهل)
- 67 = **siebenundsechzig** (هفت و شصت)
- 99 = **neunundneunzig** (نه و نود)

## Rules for Ordinals

| Rule | Example |
|------|---------|
| 1.-19: add **-te** | dritte, vierte, fünfte |
| 20+: add **-ste** | zwanzigste, dreißigste |
| Exceptions: erste (1st), dritte (3rd), siebte (7th), achte (8th) | irregular forms |
