## 1. Einleitung (Introduction) | مقدمه

**English:** The introduction sets the topic, provides context, and presents the thesis or main question.

**Persian:** مقدمه موضوع را معرفی می‌کند، زمینه ارائه می‌دهد و فرضیه یا سؤال اصلی را مطرح می‌کند.

### Structure | ساختار

| Element | Purpose | Example |
|---|---|---|
| **Hook** | Grab attention | In der heutigen Welt ist... |
| **Context** | Background information | In den letzten Jahren... |
| **Thesis** | Main argument/question | Diese Arbeit untersucht die Frage, ob... |
| **Outline** | Preview of structure | Zunächst wird... dann... abschließend... |

### Useful Phrases | عبارات مفید

| German | English | Persian |
|---|---|---|
| In der heutigen Welt... | In today's world... | در دنیای امروز... |
| Seit einiger Zeit... | For some time now... | از مدتی پیش... |
| Es ist bekannt, dass... | It is known that... | مشخص است که... |
| Die Frage ist, ob... | The question is whether... | سؤال این است که آیا... |
| Ziel dieser Arbeit ist es... | The aim of this work is... | هدف این کار... |
| Zunächst soll geklärt werden... | First, it should be clarified... | ابتدا باید روشن شود... |

### Example Introduction | مثال مقدمه

```
In den letzten Jahren hat sich die Digitalisierung stark 
verändert. Die Frage ist, ob die Schule mit dieser 
Entwicklung Schritt halten kann. Ziel dieser Arbeit ist 
es, die Vorteile und Nachteile der Digitalisierung in der 
Schule zu untersuchen.
```

## 2. Hauptteil (Main Body) | بخش اصلی

**English:** The main body presents arguments, evidence, and analysis in a logical order.

**Persian:** بخش اصلی استدلال‌ها، شواهد و تحلیل را به ترتیب منطقی ارائه می‌دهد.

### Structure | ساختار

| Element | Purpose | Example |
|---|---|---|
| **Topic sentence** | Introduce paragraph idea | Ein wichtiger Vorteil ist... |
| **Argument** | Main point | Die Digitalisierung ermöglicht... |
| **Evidence** | Support with data/examples | Eine Studie von 2023 zeigt... |
| **Analysis** | Explain significance | Das bedeutet, dass... |
| **Linking** | Connect to next paragraph | Ein weiterer Aspekt ist... |

### Useful Phrases | عبارات مفید

| German | English | Persian |
|---|---|---|
| Ein wichtiger Vorteil ist... | An important advantage is... | یک مزیت مهم... |
| Dagegen spricht, dass... | Against this speaks... | در مقابل این... |
| Eine Studie zeigt, dass... | A study shows that... | یک مطالعه نشان می‌دهد که... |
| Das bedeutet, dass... | This means that... | این به این معناست که... |
| Ein weiterer Aspekt ist... | A further aspect is... | جنبه دیگر... |
| Im Gegensatz dazu... | In contrast to this... | در مقابل این... |
| Außerdem... | Furthermore... | علاوه بر این... |
| Darüber hinaus... | Moreover... | علاوه بر این... |
| Ein Beispiel dafür ist... | An example of this is... | یک مثال برای این... |
| Zusammenfassend lässt sich sagen... | In summary... | به طور خلاصه... |

## 3. Schluss (Conclusion) | نتیجه‌گیری

**English:** The conclusion summarizes the main points, restates the thesis, and may offer recommendations or outlook.

**Persian:** نتیجه‌گیری نکات اصلی را خلاصه می‌کند، فرضیه را بازگو می‌کند و ممکن است پیشنهادات یا چشم‌انداز ارائه دهد.

### Structure | ساختار

| Element | Purpose | Example |
|---|---|---|
| **Summary** | Recap main points | Zusammenfassend lässt sich sagen... |
| **Restate thesis** | Answer the question | Die Frage, ob... lässt sich bejahen. |
| **Recommendation** | Suggest action | Es wäre ratsam, dass... |
| **Outlook** | Future perspective | In Zukunft wird... |

### Useful Phrases | عبارات مفید

| German | English | Persian |
|---|---|---|
| Zusammenfassend lässt sich sagen... | In summary... | به طور خلاصه... |
| Abschließend lässt sich festhalten... | In conclusion... | در نهایت... |
| Die Frage, ob... lässt sich bejahen. | The question whether... can be answered affirmatively. | سؤال... را می‌توان مثبت پاسخ داد. |
| Es wäre ratsam, dass... | It would be advisable that... | توصیه می‌شود که... |
| In Zukunft wird... erwartet. | In the future, ... is expected. | در آینده... انتظار می‌رود. |
| Ein Ausblick auf... | An outlook on... | چشم‌اندازی بر... |

## 4. Argumentation | استدلال

**English:** Argumentation involves presenting reasons and evidence to support or refute a claim.

**Persian:** استدلال شامل ارائه دلایل و شواهد برای حمایت یا رد یک ادعاست.

### Argument Structure | ساختار استدلال

| Element | Example |
|---|---|
| **Behauptung** (Claim) | Das Internet ist nützlich. |
| **Begründung** (Reason) | Weil man schnell Informationen findet. |
| **Beispiel** (Example) | Zum Beispiel kann man Nachrichten online lesen. |
| **Fazit** (Conclusion) | Daher ist das Internet ein wichtiges Werkzeug. |

### Useful Phrases | عبارات مفید

| Function | German | English | Persian |
|---|---|---|---|
| **Claim** | Ich bin der Meinung, dass... | I am of the opinion that... | من معتقدم که... |
| **Reason** | Denn... / Weil... | Because... | زیرا... / چون... |
| **Example** | Zum Beispiel... / Zum Beispiel... | For example... | به عنوان مثال... |
| **Conclusion** | Daraus folgt, dass... | It follows that... | نتیجه می‌شود که... |
| **Concession** | Zwar ist... aber... | Granted, ... but... | هرچند... اما... |
| **Counter-argument** | Dagegen spricht, dass... | Against this speaks... | در مقابل این... |

## 5. Discussion | بحث

**English:** Discussion involves examining different perspectives on a topic.

**Persian:** بحث شامل بررسی دیدگاه‌های مختلف درباره یک موضوع است.

### Structure | ساختار

| Element | Purpose |
|---|---|
| **Thesis** | Present one perspective |
| **Antithesis** | Present opposing perspective |
| **Synthesis** | Combine or evaluate both |

### Useful Phrases | عبارات مفید

| German | English | Persian |
|---|---|---|
| Auf der einen Seite... auf der anderen Seite... | On the one hand... on the other hand... | از یک طرف... از طرف دیگر... |
| Man könnte einwenden, dass... | One could object that... | می‌توان اعتراض کرد که... |
| Dem ist allerdings zu entgegnen... | However, this can be countered... | اما این را می‌توان پاسخ داد... |
| Es gibt verschiedene Meinungen... | There are different opinions... | نظرات مختلفی وجود دارد... |
| Meiner Meinung nach... | In my opinion... | به نظر من... |
| Ich stimme dem zu, dass... | I agree that... | موافقم که... |
| Ich bin dagegen, dass... | I am against... | مخالف این هستم که... |

## 6. Comparison | مقایسه

**English:** Comparison involves examining similarities and differences between two or more things.

**Persian:** مقایسه شامل بررسی شباهت‌ها و تفاوت‌ها بین دو یا چند چیز است.

### Useful Phrases | عبارات مفید

| German | English | Persian |
|---|---|---|
| Ähnlich wie... | Similar to... | مشابه... |
| Im Vergleich zu... | In comparison to... | در مقایسه با... |
| Im Gegensatz zu... | In contrast to... | در مقابل... |
| Sowohl... als auch... | Both... and... | هم... و هم... |
| Entweder... oder... | Either... or... | یا... یا... |
| Während... ist... | While... is... | در حالی که... است... |
| Der größte Unterschied ist... | The biggest difference is... | بزرگترین تفاوت... |
| Beide haben gemeinsam, dass... | Both have in common that... | هر دو مشترک هستند که... |
