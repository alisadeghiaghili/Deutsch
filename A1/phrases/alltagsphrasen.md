## Greetings & Goodbyes

### Greetings (Begrüßungen)

| German | English | Persian | When to Use |
|--------|---------|---------|-------------|
| **Guten Morgen!** | Good morning! | صبح بخیر! | Morning (until ~10am) |
| **Guten Tag!** | Good day! | روز بخیر! | Daytime (formal) |
| **Guten Abend!** | Good evening! | عصر بخیر! | Evening |
| **Hallo!** | Hello! | سلام! | Informal anytime |
| **Hi!** | Hi! | سلام! | Very informal |
| **Servus!** | Hi/Bye! | سلام/خداحافظ! | Southern Germany/Austria |
| **Grüß Gott!** | Hello! | سلام! | Southern Germany/Austria |
| **Na?** | Hey/What's up? | سلام/خوبی؟ | Very informal |
| **Wie geht es Ihnen?** | How are you? (formal) | حالتون چطوره؟ | Formal |
| **Wie geht's?** | How are you? (informal) | خوبی؟ | Informal |
| **Mir geht's gut, danke.** | I'm fine, thanks. | خوبم، ممنون. | Response |
| **Und Ihnen?** | And you? (formal) | شما چطور؟ | Formal response |
| **Und dir?** | And you? (informal) | تو چطور؟ | Informal response |
| **Nicht so gut.** | Not so good. | خوب نیستم. | Negative response |

### Goodbyes (Verabschiedungen)

| German | English | Persian | When to Use |
|--------|---------|---------|-------------|
| **Tschüss!** | Bye! | خداحافظ! | Informal |
| **Tschüssi!** | Bye bye! | خداحافظ! | Very informal/cute |
| **Auf Wiedersehen!** | Goodbye! | خداحافظ! | Formal |
| **Bis bald!** | See you soon! | تا به زودی! | Informal |
| **Bis morgen!** | See you tomorrow! | تا فردا! | Informal |
| **Bis später!** | See you later! | تا بعد! | Informal |
| **Bis dann!** | See you then! | تا اونموقع! | Informal |
| **Gute Nacht!** | Good night! | شب بخیر! | Before sleeping |
| **Mach's gut!** | Take care! | مراقب خودت باش! | Informal |
| **Pass auf dich auf!** | Take care! | مراقب خودت باش! | Informal |

## Common Expressions (Redewendungen)

| German | English | Persian |
|--------|---------|---------|
| **Natürlich!** | Of course! | البته! |
| **Selbstverständlich!** | Of course! | البته! |
| **Kein Wunder!** | No wonder! | جای تعجب نیست! |
| **Macht nichts!** | It doesn't matter! | اهمیتی ندارد! |
| **Stimmt!** | That's right! | درسته! |
| **Genau!** | Exactly! | دقیقاً! |
| **Echt?** | Really? | واقعاً؟ |
| **Wirklich?** | Really? | واقعاً؟ |
| **Das ist toll!** | That's great! | عالیه! |
| **Das ist super!** | That's super! | عالیه! |
| **Ich verstehe nicht.** | I don't understand. | نمی‌فهمم. |
| **Können Sie das bitte wiederholen?** | Can you repeat that please? | لطفاً دوباره بگویید. |
| **Sprechen Sie bitte langsamer.** | Please speak more slowly. | لطفاً آهسته‌تر صحبت کنید. |
| **Wie sagt man... auf Deutsch?** | How do you say... in German? | ... به آلمانی چه می‌گویند؟ |
| **Was bedeutet das?** | What does that mean? | آن به چه معناست؟ |
| **Ich lerne Deutsch.** | I'm learning German. | من آلمانی یاد می‌گیرم. |
| **Ich spreche nicht gut Deutsch.** | I don't speak German well. | خوب آلمانی صحبت نمی‌کنم. |
| **Können Sie mir helfen?** | Can you help me? | می‌توانید کمکم کنید؟ |
| **Ich komme aus...** | I come from... | من از ... آمده‌ام. |
