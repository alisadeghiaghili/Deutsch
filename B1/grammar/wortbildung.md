# Wortbildung – Word Formation
# ساخت کلمه

## Overview / مرور کلی

German word formation (Wortbildung) creates new words by adding prefixes, suffixes, or combining existing words. This is essential for expanding vocabulary.

ساخت کلمه در آلمانی با اضافه پیشوندها، پسوندها یا ترکیب کلمات موجود، کلمات جدید می‌سازد. این برای گسترش واژگان ضروری است.

---

## Prefixes (Vorsilben) / پیشوندها

### Prefixes that change meaning of verbs:

| Prefix | Meaning | Example | Translation | فارسی |
|--------|---------|---------|-------------|-------|
| ver- | change, make | machen -> ver**machen** | to mess up | خراب کردن |
| be- | make, cause | Arzt -> **be**handeln | to treat | درمان کردن |
| ent- | remove, reverse |decken -> **ent**decken | to discover | کشف کردن |
| er- | achieve, result |fahren -> **er**fahren | to experience | تجربه کردن |
| zer- | destroy, break | legen -> **zer**legen | to dismantle | باز کردن |
| miss- | wrongly, badly | verstehen -> **miss**verstehen | to misunderstand | سوءتفاهم داشتن |
| ge- | past participle marker | gemacht | done | انجام شده |
| vor- | before, forward | fahren -> **vor**fahren | to drive up | جلو آمدن |
| zurück- | back | kommen -> **zurück**kommen | to come back | برگشتن |

### Prefixes with nouns and adjectives:

| Prefix | Example | Meaning | فارسی |
|--------|---------|---------|-------|
| un- (negative) | **un**glücklich | unhappy | ناخوشحال |
| ent- (opposite) | **Ent**wicklung | development | توسعه |
| erz- (archaic) | **Erz**feind | archenemy | دشمن قسم‌خورده |

## Compound Nouns (Zusammensetzungen) / اسم‌های مرکب

German creates compound nouns by combining two or more words. The **last word** determines the gender.

آلمانی اسم‌های مرکب را با ترکیب دو یا چند کلمه می‌سازد. **کلمه آخر** جنسیت را تعیین می‌کند.

### Examples:

| Compound | Parts | Meaning | فارسی |
|----------|-------|---------|-------|
| **Handschuh** | Hand + Schuh | glove (hand-shoe) | دستکش |
| **Fahrkarte** | fahren + Karte | ticket (drive-card) | بلیط |
| **Flughafen** | fliegen + Hafen | airport (fly-haven) | فرودگاه |
| **Wörterbuch** | Wörter + Buch | dictionary (words-book) | فرهنگ لغت |
| **Kühlschrank** | kühl + Schrank | refrigerator (cool-cupboard) | یخچال |
| **Bahnhof** | Bahn + Hof | train station (track-yard) | ایستگاه قطار |
| **Schulbus** | Schule + Bus | school bus | اتوبوس مدرسه |
| **Stundenplan** | Stunde + Plan | timetable (hour-plan) | برنامه زمانی |
| **Regenschirm** | Regen + Schirm | umbrella (rain-shield) | چتر |
| **Handytasche** | Handy + Tasche | phone case (mobile-bag) | کیف گوشی |

### Rules for compounds:

| Rule | Example | Explanation |
|------|---------|-------------|
| Last word = gender | der **Kühlschrank** (masculine) | From "der Schrank" |
| Add -s/-es between parts | Hand**s**chuh, Freundschaft | Connecting element |
| No spaces | Handschuh (not Hand Schuh) | Written as one word |
| Capitalize all parts | Kinder**garten** | Both parts are capitalized |

## Examples in Context / مثال‌های در متن

### Using compounds:
> Ich fahre mit dem **Fahrstuhl** (fahren + Stuhl) in den **Dachgeschoss** (Dach + Geschoss). Dort gibt es ein **Schwimmbad** (schwimmen + Bad). Nach dem **Schwimmen** gehe ich in die **Umkleidekabine** (Umkleide + Kabine).

### Using prefixes:
> Er **entdeckt** (ent- + decken) eine neue Methode. Er **versucht** (ver- + suchen) es jeden Tag. Er **erklärt** (er- + klären) es seinen **Schülern** (Schüler). Er **bemerkt** (be- + merken) Fortschritte.

## Key Points / نکات کلیدی

1. **Compound nouns** = last word determines gender and meaning
2. **Prefixes** can completely change a verb's meaning
3. **Suffixes** determine the part of speech (noun, adjective, verb)
4. Compounds are always written as **one word**
5. All parts of a compound are **capitalized**
6. German loves compounds – they are very common
7. Learning word formation helps you **decode unfamiliar words**

**نکات کلیدی:**
1. **اسم‌های مرکب** = کلمه آخر جنسیت و معنا را تعیین می‌کند
2. **پیشوندها** می‌توانند معنای فعل را کاملاً تغییر دهند
3. **پسوندها** نوع کلمه را تعیین می‌کنند (اسم، صفت، فعل)
4. اسم‌های مرکب همیشه به صورت **یک کلمه** نوشته می‌شوند
5. تمام بخش‌های یک اسم مرکب **با حرف بزرگ** نوشته می‌شوند
6. آلمانی عاشق اسم‌های مرکب است – بسیار رایج هستند
7. یادگیری ساخت کلمه به شما کمک می‌کند کلمات ناآشنا را **رشکایی** کنید
