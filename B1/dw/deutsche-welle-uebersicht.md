## Lernstrategien / Learning Strategies

### Für DW Kurse / For DW Courses

1. **Tägliches Hören / Daily Listening:**
   - Hören Sie jeden Tag 15-30 Minuten DW-Inhalte
   - Listen to DW content for 15-30 minutes daily

2. **Aktives Lernen / Active Learning:**
   - Machen Sie die Übungen aktiv
   - Do the exercises actively

3. **Wortschatz führen / Vocabulary Journal:**
   - Schreiben Sie neue Wörter auf
   - Write down new words

4. **Wiederholung / Repetition:**
   - Wiederholen Sie gelerntes regelmäßig
   - Review learned material regularly

5. **Sprechpraxis / Speaking Practice:**
   - Sprechen Sie laut mit
   - Speak along with the audio

6. **Notizen machen / Taking Notes:**
   - Schreiben Sie wichtige Sätze auf
   - Write down important sentences

7. **Kontext lernen / Context Learning:**
   - Lernen Sie Wörter im Kontext
   - Learn words in context

8. **Fehler analysieren / Error Analysis:**
   - Analysieren Sie Ihre Fehler
   - Analyze your mistakes

## Prüfungsvorbereitung / Exam Preparation

### B1 Prüfung / B1 Exam

**Goethe-Zertifikat B1:**
- Lesen (Reading): 65 minutes
- Hören (Listening): 40 minutes
- Schreiben (Writing): 60 minutes
- Sprechen (Speaking): 15 minutes

**TestDaF:**
- Lesen (Reading): 60 minutes
- Hören (Listening): 40 minutes
- Schreiben (Writing): 60 minutes
- Sprechen (Speaking): 15 minutes

### Tipps für die Prüfung / Tips for the Exam

1. **Zeitmanagement / Time Management:**
   - Üben Sie mit Timer
   - Practice with a timer

2. **Prüfungsformat kennen / Know the Exam Format:**
   - Informieren Sie sich über die Prüfung
   - Inform yourself about the exam

3. **Übungsmaterialien / Practice Materials:**
   - Nutzen Sie alte Prüfungen
   - Use past exams

4. **Schwächen verbessern / Improve Weaknesses:**
   - Arbeiten Sie an Ihren Schwächen
   - Work on your weaknesses

5. **Selbstvertrauen / Confidence:**
   - Trauen Sie sich
   - Be confident
